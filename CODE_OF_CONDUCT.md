# Code of conduct

Treat contributors and learners with respect. Critique claims and code rather than
people. Harassment, discriminatory language, threats, unwanted sexual attention,
and publication of another person's private information are not acceptable.

Geographical names, borders and state recognition can be disputed. Discuss them
with dated primary sources and neutral wording. A content disagreement does not
justify personal attacks or assumptions about a contributor's identity.

This policy applies to project issues, pull requests, discussions and other
project spaces. The repository owner moderates those spaces and may remove
content, close a discussion or restrict participation. Moderation should be
proportionate to the conduct and its effect on other participants.

For conduct on GitHub, use [GitHub's abuse reporting
channel](https://github.com/contact/report-abuse). Include links and relevant
context, and do not reproduce private information in a public issue. If the
reported conduct involves the repository owner, GitHub's independent reporting
channel remains available.
