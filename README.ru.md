# Ultimate Geography · RU / EN

[English documentation](README.md)

Независимый форк [anki-geo/ultimate-geography](https://github.com/anki-geo/ultimate-geography)
с исправлениями из предоставленной русскоязычной колоды, английским переводом
пояснений и адаптивным оформлением. Источником разработки являются CSV, HTML и CSS
в репозитории. Исходный `.apkg` нужен только для необязательной проверки миграции.

В каждом языке **323 заметки и 982 карточки** четырёх исходных типов:
страна → столица, столица → страна, флаг → страна, карта → географический объект.
Приложение содержит 319 заметок и 978 карточек. Ещё четыре объекта уже находились
в upstream и сохранены: Малаккский, Ормузский, Гибралтарский проливы и Оманский залив.
Новые направления и категории не добавлены.

Добавлены 221 пояснение к флагам и 323 пояснения к картам. Уточнены статусы столиц,
административных центров и запланированных переносов. Справка на обороте всегда
открыта. Карточки широкие на компьютере, изображения располагаются вертикально
на узких экранах. Ширина отдельной панели карты ограничена. Личные подколоды,
приоритеты, правила оценивания и настройки обучения в публичные сборки не включены.
[Отчёт миграции](doc/reference-audit.json) объясняет отличия;
[реестр источников](doc/content-sources.csv) содержит даты проверки существенных фактов.

## Установка и обновление

Скачайте релизный ZIP нужного языка, распакуйте его и импортируйте `.apkg` через
**Файл → Импорт** в Anki. Изображения включены. Для APKG не требуется CrowdAnki.
RU и EN можно импортировать в одну коллекцию в любом порядке: GUID разных языков
не пересекаются, типы заметок и колоды называются `Ultimate Geography [RU]` и `[EN]`.

Перед обновлением синхронизируйте коллекцию и создайте резервную копию. Импортируйте
новый APKG того же языка. При переходе с приложенной исправленной колоды выберите
обновление заметок и типов заметок **Всегда** и включите **Объединять типы заметок**.
Импорт прогресса обучения и настроек колоды оставьте выключенным. Русский числовой
ID типа заметки и все языковые GUID сохранены; карточки сохраняют ID и историю
повторений. Новые заметки добавляются без истории. Старые карточки могут остаться
в прежних подколодах, их можно переместить через браузер Anki.

Не удаляйте прежние заметки перед обновлением. Изменённые локально поля и оформление
могут быть заменены. Для типа заметок с вручную изменёнными именами полей или
идентичностью потребуется отдельная миграция. Тип из приложения переименовывается
в `Ultimate Geography [RU]`.

CrowdAnki по-прежнему поддерживается: после сборки импортируйте каталог
`build/Ultimate Geography [RU]` или `[EN]`. Русской колоде назначен отдельный UUID,
чтобы она не использовала идентичность английской. Проверенный путь миграции:
APKG с объединением типов. Чередование APKG и CrowdAnki требует резервной копии
и проверки журналов импорта.

## Сборка

Нужны [uv](https://docs.astral.sh/uv/) и **CPython 3.10–3.15** со стандартной
сборкой с GIL. `.python-version` выбирает 3.14 по умолчанию. Зависимости описаны
в `pyproject.toml` и зафиксированы в `uv.lock`. uv управляет окружением `.venv`;
активировать его вручную не требуется.

```sh
uv sync --locked
uv run --locked python utils/generate_and_build.py recipes/source_to_anki.yaml
uv run --locked python utils/generate_and_build.py 'recipes/source_to_anki_[experimental].yaml'
uv run --locked python utils/verify_sources.py
```

Чтобы выбрать другую поддерживаемую версию для всех команд текущего терминала,
выполните `export UV_PYTHON=3.15` перед установкой зависимостей и запуском. Для
одной команды можно указать версию явно:
`uv run --locked --python 3.15 --group export python utils/export_apkg.py`.
Lock-файл охватывает все шесть версий. На Python 3.10 используется Markdown 3.10.3,
на более новых версиях Python используется Markdown 3.11.2. Для совместимости с
Python 3.15 обновлены PyYAML до 6.0.3 и ruamel.yaml.clib до 0.2.15. На проверенной
macOS эти два пакета под 3.15 собираются из исходников: нужны компилятор C и
заголовочные файлы Python. Brain Brew остаётся версии 0.3.11. CI выполняет обе
сборки и проверки APKG на каждой поддерживаемой версии. Точные локально
проверенные интерпретаторы и платформы указаны в [отчёте](doc/VALIDATION.md).

Сохраняются стандартные, расширенные и экспериментальные сборки upstream.
Публичные APKG этого форка выпускаются только для стандартных RU и EN.
Правьте `src/data/*.csv`, общие шаблоны в `src/note_models/templates/ru-en`, подписи
в `src/note_models/translations.csv` и `src/note_models/style_ru_en.css`.
Поля `Flag_Note` и `Map_Note` добавлены после восьми исходных полей. Другие языки
продолжают использовать первоначальные шаблоны и стили.

Группа зависимостей `export` содержит **Anki backend 26.9.3**. Он работает в том же
выбранном окружении Python 3.10–3.15; установленный интерфейс Anki и `PYTHONPATH`
больше не нужны:

```sh
uv run --locked --group export python utils/export_apkg.py
uv run --locked --group export python utils/verify_release.py
uv run --locked --group export python utils/audit_reference.py '/путь/к/исправленной.apkg'
```

Для проверки обновления исходной колоды с сохранением истории передайте
`--reference '/путь/к/исправленной.apkg'` скрипту `verify_release.py`. CI проверяет
публичные сборки без личного файла. Команда `uv sync --locked --group export`
заранее устанавливает зависимости сборки, линтера и экспорта вместе.

Результат: `build/releases/Ultimate_Geography_2026.10.20_RU.apkg` и
`Ultimate_Geography_2026.10.20_EN.apkg`, соответствующие ZIP с лицензиями и атрибуцией,
JSON с хешами пакетов и содержимого. Для новой редакции задавайте более поздний
`SOURCE_DATE_EPOCH`; по умолчанию используется 2026-10-20 UTC. Внутренние ID базы
и метаданные ZIP назначает Anki, поэтому побайтовое совпадение APKG не гарантируется.
Содержимое и GUID воспроизводимы. Сборки создаются в одноразовых коллекциях без
истории, расписания автора и личных настроек. `build/` исключён из Git.

## Форматирование и линтеры

Ruff включён в стандартную группу `dev`: базовые проверки ошибок Python, сортировка
импортов и форматирование с отступом 4 пробела и длиной строки 100 символов.

```sh
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked ruff check --fix .
uv run --locked ruff format .
```

Biome зафиксирован в `package-lock.json`. Нужны Node.js 24 и npm:

```sh
npm ci --ignore-scripts
npm run check
npm run format
```

Biome обрабатывает JavaScript проекта (`utils/*.cjs`), CSS моделей заметок и JSON
конфигурации и документации. Явный список файлов исключает HTML-шаблоны Anki с
обязательным разделителем `--`, CSV, YAML, Markdown, SVG, сторонние медиа,
сгенерированные шаблоны и `build/`. CSV проверяет `verify_sources.py`. Только для
CSS отключены два правила, конфликтующие с намеренным порядком каскада и
переопределениями Anki через `!important`. CI проверяет
форматирование без записи изменений. Dependabot проверяет uv, npm и GitHub Actions
раз в месяц, группируя обновления и ограничивая число PR.

Браузерная проверка: `node utils/verify_layout.cjs` при уже доступных Playwright и
Chromium. Playwright не добавлен в зависимости проекта. HTML создаёт
`verify_release.py`, результаты находятся в `build/qa/`. Скрипт не скачивает
зависимости или браузеры. Для Chromium вне стандартного кеша задайте
`UG_CHROMIUM_PATH`, для общего каталога Node-пакетов при необходимости задайте
`NODE_PATH`.

## Проверки и лицензии

После сборки колод и экспорта RU/EN APKG запустите регрессионные тесты:

```sh
uv run --locked --group export python -m unittest discover -s utils -p 'test_*.py' -v
```

Тесты на стандартном `unittest` проверяют упаковку ZIP рядом с `build/qa` и
`build/releases`, чтение и запись UTF-8 при другой системной кодировке, отклонение
неверного эталонного пакета, импорт и обновление с сохранением истории.
Используются временные архивы и коллекции Anki; личный исходный APKG не нужен.
CI запускает тесты на всех версиях Python из матрицы совместимости.

[Протокол](doc/VALIDATION.md) перечисляет выполненные проверки и версии инструментов.
Проверка Python API Anki не означает запуск интерфейса Anki. Проверка Chromium на
мобильных ширинах не означает тестирование на Pixel 8, в AnkiDroid или AnkiMobile.
Проверенные инструменты: Anki backend **26.9.3** и Chromium **156.0.8078.4**.

Для кода, содержимого, шаблонов и иконки действует **Unlicense** upstream.
Изображения имеют собственные лицензии: исходные ссылки, условия и изменения
сохранены в `sources.csv`, сведения об авторах дополнены в `media-attribution.csv`.
Передавайте эти файлы и `LICENSE.md` вместе с колодой; полный комплект находится в ZIP.
Изображения upstream не заменены отличающимися файлами из приложения с неустановленной
историей редакций. Обозначение `kaiu` не рассматривается как доказательство отдельного
вклада или дополнительной лицензии. Весь форк не объявляется Apache-2.0.

`CONTRIBUTING.md` сохраняет руководство по модели данных и рецептам upstream.
Команды и количества для этого форка приведены выше.
